# 빛의 밝기와 거리 — 2차시 수업 자료

중학교 2학년 과학 **Ⅷ. 별과 우주 — 1. 별 — 밝기에 따른 별의 등급 (1)** (교과서 272~273쪽) 45분 수업용 HTML 자료입니다.

| 단계 | 시간 | 내용 |
|---|---|---|
| ① 생각 열기 | 5분 | 응원 봉의 밝기, 예상하기 |
| ② 탐구 | 15분 | 20·40·60 cm에서 빛의 세기 측정 → 평균·비·그래프 (기기가 없을 때는 가상 조도계) |
| ③ 왜 그럴까? | 10분 | 같은 양의 빛이 1칸·4칸·9칸으로 퍼지는 모형 |
| ④ 적용 | 7분 | 거리와 내는 빛의 양이 다른 두 별의 보이는 밝기 비교 |
| ⑤ 확인 문제 | 6분 | 6문항 |
| ⑥ 정리 | 2분 | 처음 예상과 비교 |
